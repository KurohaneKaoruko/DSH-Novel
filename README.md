# DSH-Novel · AI 网文写作环境

> 一个 Agent 预设，把 DeepSeek Harness 变成「AI 写小说」工作台：**25 个网文写作工具 + 完整网文创作方法论**，全部随「小说助手」预设内置、持久可用，**无需额外安装任何插件**。
> 把本仓库（或 GitHub 链接）交给任意 DeepSeek Harness Agent，按 `INSTALL.md` 执行即可自动安装完成。

---

## 一、这是什么

本项目只包含一件东西——**「小说助手」Agent 预设**。它以写小说为核心，把 DSH 变成一位专业网文写作助手：

| 组件 | 类型 | 作用 |
| --- | --- | --- |
| **小说助手（novelist）** Agent 预设 | 用户 Agent 预设（持久） | ① **25 个 `novel_*` 写作工具**（内置 `novel-tools.mjs`）：润色、续写、**去 AI 味**、**作品工程**、大纲整理/优化/续写、小说分析、拆书学习、灵感生成、世界观构建、角色设计、章节规划、场景写作、黄金三章、书名/标题、简介与梗概、作品评阅、改写、对话优化、文学翻译、剧情漏洞排查、起名、文风设定、情节推演——每个工具都会调用当前会话模型做**真正的文本生成**，并遵守「去 AI 味写作红线」；<br>② **以写小说为核心的人设** + 完整的《网文创作方法论》提示段（黄金三章法则、爽点公式、节奏钩子、伏笔闭环、长篇工程、成稿流程、去 AI 味自查、Obsidian 落盘约定）；<br>③ 标准工作台：文件读写、网页检索、子代理与工作流、目标与待办、计划模式。 |

**为什么不需要插件？** 写作能力由「Agent 本身 + 预设内置工具」共同承载：工具负责把每个专业动作（润色、续写、拆书……）用聚焦的专家提示词完成，方法论与人设让 Agent 在无工具场景下也能独立以同等标准写作。两者都已随预设持久内置，因此**不需要任何动态插件**——省去安装、授权与进程重启后重装的麻烦。


## 三、安装

### 方式一：交给 DSH 自动安装（推荐）

1. 把本仓库目录（或 GitHub 链接）交给任意 DeepSeek Harness Agent，例如：
   > “请把 DSH-Novel 项目安装到当前环境，按 INSTALL.md 执行。”
2. Agent 会按 `INSTALL.md` 完成：
   - 把 `agent-presets/novelist/` 复制到 DSH 用户预设根目录 `~/.dsh/.agent-presets/novelist`；
   - 用 `agentPresets.standingKeyFor('novelist')` 做挂载校验；
   - 完成后新建会话选择「小说助手」即可开始写作。**无需安装任何插件、无需浏览器授权。**

### 方式二：手动安装

见 `INSTALL.md` 中的逐条步骤（同一套内容，供手动执行）。

## 四、使用

- **日常写作**：新建会话 → 预设选择「**小说助手**」→ 直接对话：
  - “把这些素材整理成大纲，再规划第一卷 10 章”
  - “接着这篇正文续写 2000 字，结尾留钩子”
  - “帮我润色这段 / 拆解这段开篇学它的钩子写法”
- **去 AI 味与工程化**：
  - “把这段去一下 AI 味：……”（`novel_deai`，体检/重写/逐句精简）
  - “初始化作品工程《书名》，把刚才写的第一章保存进去，再生成伏笔清单”（`novel_project`，自动建 `正文/大纲/设定集/人物卡/伏笔清单` 并落盘）
- **让 Agent 把成果落盘**：让 Agent 把章节、大纲、设定集以 Markdown 保存到工作区，之后用 Obsidian 阅读与批注（见下节）。

## 五、搭配 Obsidian 使用

本项目非常适合搭配 **Obsidian** 一起使用：把「小说助手」的工作区（或专门的写作目录）直接作为 Obsidian 的 **Vault**。

- Agent 产出的章节、大纲、设定集、人物卡、伏笔清单全部是 Markdown 文件，天然就是 Obsidian 笔记——无需任何转换。
- 在 Obsidian 里**阅读与批注**成稿：正文排版、高亮、评论随手可加，改完后把文件放回工作区，告诉 Agent「继续写」，它会读到你的修改。
- 用**双链**把角色、地点、事件、势力互相关联，用**图谱视图**看清设定网络与伏笔脉络；用**标签**与**看板**跟踪连载进度、分卷与更新状态。
- 写作闭环：**Agent 生成 → Obsidian 阅读批注 → 反馈给 Agent → 迭代**，人工与 AI 各取所长。

## 六、说明

- **持久性**：整个项目就是一个 Agent 预设，随 `~/.dsh/.agent-presets/novelist` 持久存在——写作工具、人设、方法论全部内置，进程重启、切换会话都不影响，无需重装任何东西。
- **模型路由**：所有工具默认调用当前会话的默认模型，每个工具都支持传入 `provider` / `model` 覆盖；无默认模型时自动兜底到第一个可用提供方。
- **去 AI 味**：工具系统提示与《网文创作方法论》内置「写作红线」——禁万能套话、具体代替抽象、克制心理独白、对话口语化、结构长短错落、正文禁 markdown 符号与 emoji。

## 七、维护

- 修改预设：编辑 `agent-presets/novelist/` 下文件，复制覆盖到 `~/.dsh/.agent-presets/novelist/`，并重新挂载校验（`agentPresets.standingKeyFor('novelist')`）。
- 卸载：删除 `~/.dsh/.agent-presets/novelist` 目录即可。
